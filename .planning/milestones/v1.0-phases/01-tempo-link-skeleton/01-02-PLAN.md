# Phase 1, Plan 02: Launchable BPM window (Tk gate + slider + nudge buttons)

## Phase Goal

**As a** rider, **I want to** set BPM in the app and hear the engine loop change tempo, **so that** I know the control chain works.

After this plan, the rider runs `./run.sh`, sees the PedalPulse window, and retempos the engine from the slider (on release) and the −5/−1/+1/+5 buttons (debounced). An interpreter with a broken or old Tk produces a clear message instead of a silent failure. Plan 03 adds the entry field and keyboard shortcuts.
