# Phase 5, Plan 02: The dropdowns only offer names the engine accepts, and nothing crashes

## Phase Goal

**As a** rider, **I want to** have Palette, Progression and Melody selectors in the PedalPulse window, **so that** I can pick Auto or any named variation using the same names I use when giving feedback.

Plan 05-01 put the three dropdowns in the window with a simple folder scan. This plan makes the scan match the engine's exact name rule, so the rider is never offered a name the engine would refuse, and an empty, missing or unreadable folder shows Auto only. It then pins the selector and send contracts in tests: send only on a real change, Auto goes out as auto, a vanished name is still sent for the engine to judge, and a failed send never crashes the app. This plan shares no file with Plan 05-03, which runs after it (wave 3), so neither plan's full-suite gate ever sees the other's work in progress.

Purpose: GUI-05 (Auto plus every valid file on disk; empty or missing folder shows Auto only, D-09) and GUI-06 (by-name send-only selection; the GUI never crashes; the engine is the validator). Implements the Claude's Discretion item "which files count as entries" and covers the GUI-05 empty/ordering and GUI-06 empty/encoding edges.
