# Phase 6, Plan 03: Seven progressions to choose from, each with its own chords and pace

## Phase Goal

**As a** rider, **I want to** hear the music move through chord progressions that bass, arp and pad follow together, **so that** it stops sounding like the same few notes for an hour.

With the strict gate from Plan 02 in place, this plan adds the other six progressions of the broad trance mix (D-04, D-05, D-06): rocker, lift, return, deep, melancholy and drama. Each is a few lines of chord data. The template becomes a chord-data recipe, and a table check pins what every shipped file must play, so a typo in a root number is caught before the file is frozen by its commit.

<objective>
Ship six new chord-data progressions plus the chord-data template, each proven by the strict static branch, the chord-follow recording loop and a table of expected chords, and see them in the app's Progression dropdown.

Purpose: HARM-02 (at least 6 named progressions plus classic), HARM-01 for every file. Implements D-04 (broad trance mix incl. one deep and one dark file), D-05 (Drama with E major), D-06 (pace per file), D-07 (written relative to the key, the engine supplies A), D-11 (each prints its own line).
Output: six new files in supercollider/library/progressions/, a rewritten _template.scd, a table check in supercollider/library_test.scd.
</objective>
