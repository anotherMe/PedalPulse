# Phase 1, Plan 01: Engine walking skeleton (tracer + loop + safety contract)

## Phase Goal

**As a** rider, **I want to** set BPM in the app and hear the engine loop change tempo, **so that** I know the control chain works.

This plan proves the risky half of that chain end to end: a Python process sends `/pp/bpm` over UDP, sclang's `OSCdef` validates and clamps it, and the dedicated TempoClock retempos a loop that plays through a −1 dBFS master limiter. Plan 02 adds the window on top of this exact client; Plan 03 adds the remaining controls.

<objective>
Build the single SuperCollider entry file and the Python OSC client, and prove with a headless automated test that Python → OSC → sclang → TempoClock works. Then grow the loop to kick + hat + A-minor bass and lock in the engine safety contract: clamping, latest-wins apply, no node leaks, limiter ceiling, idempotent re-evaluation, and loopback-only control.

Purpose: Everything later (GUI, glides, EPIC, heartbeat) rides on this contract. Proving it first, on the best context, catches an architectural dead end after one commit.
Output: `supercollider/main.scd`, `supercollider/smoke_test.scd`, `scripts/smoke_test.sh`, `python_app/config.py`, `python_app/osc_client.py`, `python_app/requirements.txt`.
</objective>

**A. `supercollider/main.scd`: the full skeleton loop (D-13). The SynthDefs must be reusable as Phase 2's starting point, so every one takes `out` and `amp` args.**

1. SynthDef `\ppHat`:
   - signal: `HPF.ar(WhiteNoise.ar, 7000)`;
   - envelope: `EnvGen.kr(Env.perc(0.001, 0.12), doneAction: 2)`;
   - amp default about 0.15; stereo out.
2. SynthDef `\ppBass`:
   - signal: a detuned pair of `Saw.ar` through `RLPF.ar` (cutoff about 600–900 Hz) at `freq` (default 55);
   - envelope: `EnvGen.kr(Env.adsr(0.005, 0.1, 0.6, 0.05), gate, doneAction: 2)`, with the `gate` arg so the Pbindef releases it;
   - amp default about 0.25; stereo out.
3. Keep `\ppKick` unchanged. Keep per-voice amps conservative so the master peaks around 0.5–0.7 at `preGain` 1. The limiter is a safety net, not the leveller (Pitfall 5).
4. Pbindef `\ppHat`: one hit on every offbeat 8th (the "and" of each beat), a classic trance offbeat hat. This is the Claude's-discretion hat choice.
5. Pbindef `\ppBass` on an 8th-note grid (`\dur, 0.5`):
   - rests on the downbeat 8ths, notes on the offbeat 8ths;
   - A minor root A1 (MIDI 33) on the offbeats of beats 1–3, and C2 (MIDI 36) on the offbeat of beat 4: the note change at the bar end;
   - `\legato` about 0.8.
6. Every Pbindef sets `\out, ~ppMixBus` and `\group, ~ppInstrGroup`. All three play with `.play(~clock, quant: 4)`, so they stay bar-aligned.
7. Idempotent re-evaluation. D-17's workflow is "edit ~preGain, re-evaluate", and re-evaluating must replace, never stack. At the start of the boot block, before recreating anything:
   - stop the three Pbindefs;
   - stop the previous `~clock` if non-nil;
   - free the previous `~ppMasterSynth`, `~ppMasterGroup` and `~ppInstrGroup` if non-nil;
   - free the previous `~ppMixBus` if non-nil;
   - reset `~ppApplyScheduled = false`, so a pending apply on the stopped clock can never wedge later messages.

   Keep `~bpm` across re-evaluation, so a fresh session starts at 120 (D-07) but re-evaluation keeps the last applied tempo. `OSCdef(\pp_bpm, ...)` re-registration already replaces by key.

**B. `supercollider/smoke_test.scd`: extend the tracer harness. Each check prints `CHECK OK: <name>` or `CHECK SKIP: <name> (<reason>)`; the first failure prints `SMOKE FAIL: <name>: <detail>` and exits 1 after `s.quit`.**

Keep the four tracer checks. Add checks with exactly these 15 names:
- `clamp 300->180`, `clamp 10->60`, `clamp 59->60`, `clamp 181->180`, `clamp 60`, `clamp 180`, `float 150.5`
