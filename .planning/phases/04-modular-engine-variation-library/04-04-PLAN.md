# Phase 4, Plan 04: One command checks every library file

## Phase Goal

**As a** rider, **I want to** have the engine split into a core plus a library of named variation files, with no change to what I hear, **so that** new variations can be added as files and switched to without ever stopping the music.

The library will grow every phase. This plan makes `bash scripts/check.sh` validate every file in it before a ride: shape, no side effects, bars that fill 4 beats, and voices that respect the limiter, Stop and gate. The check can provably fail, through deliberate negative controls, and it fails if any file was silently skipped. It also adds the authoring templates and a plain-language README for trying a variation by name.

<objective>
Extend `supercollider/library_test.scd` with a server-free static tier (one `LIBCHECK OK` line per file, plus negative controls) and a voice tier on a bare isolated server (with three bad-voice negative controls). Add the three `_template.scd` files, the `LIBCHECK` count cross-check in `scripts/check.sh`, the quant probe, and `supercollider/library/README.md`.

Purpose: LIB-06 (an automated check validates every library file and runs with the smoke suite), LIB-02 (every file is known by its stem, and every selectable stem round-trips), LIB-03 (the README states the never-edit rule next to the guard). Delivers the D-07 documented one-liner, and the assumption-delta invariant test recorded in Plan 01.
Output: modified `library_test.scd` and `scripts/check.sh`; new `_template.scd` ×3 and `library/README.md`.
</objective>
