# Phase 4, Plan 06: Re-evaluating never stacks, Stop silences everything, and the listening check

## Phase Goal

**As a** rider, **I want to** have the engine split into a core plus a library of named variation files, with no change to what I hear, **so that** new variations can be added as files and switched to without ever stopping the music.

This plan closes the phase's standing exit gate (ENG-05), which every later engine phase inherits. Re-evaluating `main.scd` or one module must leave exactly one copy of every layer, clock and routine, and Stop must silence the new lead too. The check uses `classic_lead`, so it cannot pass vacuously. The plan ends with the full one-command check and the rider's listening check.

Fix `supercollider/main.scd` only if a check exposes a real defect. Then run the whole gate and the end-of-phase listening check.

Purpose: ENG-05 (re-evaluating never stacks routines or leaks nodes; Stop silences every new layer and source) and the audible half of LIB-01 (D-01: the short listening check by the user).
Output: modified `supercollider/smoke_test.scd`; `supercollider/main.scd` only if a defect is found.
