# Phase 7, Plan 05: The last three sound worlds, and the one command for the CPU check next to Zwift

## Phase Goal

**As a** rider, **I want to** have the engine change its whole sound set every few minutes, or keep one I like, **so that** a long ride never sounds the same and I can name what I want more or less of.

This plan completes D-01's broad trance mix with `pluck`, `warm` and `air`, each tuned against classic before it is frozen, and gives the rider the single command D-15 asks for: lock the heaviest palette at VO2 for a minute and print scsynth's CPU, to run once with Zwift open.

Planner decision (RESEARCH Open Question 3): the CPU command picks the heaviest palette itself with a short pass over every palette at VO2, so it stays right when palettes are added; a name argument overrides it.
