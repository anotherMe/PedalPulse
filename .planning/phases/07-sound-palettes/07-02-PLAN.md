# Phase 7, Plan 02: A broken or careless file can never damage the engine or another palette's sound

## Phase Goal

**As a** rider, **I want to** have the engine change its whole sound set every few minutes, or keep one I like, **so that** a long ride never sounds the same and I can name what I want more or less of.

Plan 04 makes Auto load every palette file on disk by itself, so before that happens this plan closes the two hardening items the rider deferred in Phase 4 (D-16). WR-01: a file can no longer return a "valid" bar with absurd numbers (hundreds of thousands of rows, a legato of 100, a note of 500) that would choke the engine. WR-02: a palette can no longer overwrite another palette's voice (for example classic's arp), and a refused palette leaves no voices behind.

<objective>
Add upper bounds to row validation (WR-01) and enforce the `pp_<name>_` voice namespace with a defs guard that removes and restores voices on refusal (WR-02), with negative tests for both.

Purpose: D-16, and PAL-04's "never bypasses the limiter" in the wider sense: no file can poison the shared mix bus or change another palette's sound. Prerequisite for Plan 04's Auto prefetch.
Output: modified validate.scd, loader.scd and library_test.scd. No library file changes (the prefix rule is already in the palette template's contract; supersaw already follows it).

Decisions recorded here:
- WR-01 bounds (RESEARCH Pattern 6): rows per bar at most 64 (checked before any row is looked at, so a huge Array is refused without a loop), dur at least 1/32 beat, legato at most 8 (not 4: the core default pad reaches 7.2 on an 8-bar chord), a Number note in -12..127, a chord at most 8 notes each in -12..127. No aggregate voice-beat budget: the durs of a valid bar sum to 4, so per-row caps already bound one layer's overlap to at most 4 x 8 x 8 = 256 voice-beats per bar.
- WR-02 prefix exemption: a role may use one of classic's own six voices (\ppKick, \ppHat, \ppClap, \ppBass, \ppArp, \ppPad) without the prefix, so `palettes/_template.scd` (all roles mapped to classic voices) and the existing `bad_defs` fixture stay statically valid. Classic itself is exempt from the prefix (its names are frozen v1) but its defs may only touch its own six names.
- WR-02 restore (the reviewer's "fallback must restore the classic voices"): with the namespace enforced, only a refused file can clobber a voice, so the restore happens at refusal time, inside the guard's undo. A replaced name owned by classic is restored by re-running classic's registered defs; one owned by another registered palette by re-running that palette's defs; one owned by no library file (for example an engine voice from main.scd) is logged as an ERROR telling the rider to re-evaluate main.scd.
</objective>
