# Phase 7, Plan 03: A palette also sets how the bass moves, and acid and dark join the library

## Phase Goal

**As a** rider, **I want to** have the engine change its whole sound set every few minutes, or keep one I like, **so that** a long ride never sounds the same and I can name what I want more or less of.

Phase 6 handed bass variety to the palettes (Phase 6 D-12). This plan adds the palette key that picks the bass rhythm (D-02) and ships the two palettes whose character needs it: `acid` with a squelchy rolling 303-style bass and `dark` with a deep kick and a gritty rolling bass.

<objective>
Add the `bassStyle` palette key (validator, core style table, renderer) with tests that pin every style to the chord rules, then author, measure and commit `acid` and `dark`.

Purpose: D-02 (sounds plus bass style), PAL-01 (more named palettes, each a coherent set of bass, arp, pad, lead and, for dark, drum sounds), PAL-04 (each matched to classic before it is frozen).
Output: modified validate.scd, harmony.scd, render.scd, library_test.scd; new palettes acid.scd and dark.scd.

Decisions recorded here (yolo mode; listed for the rider in Plan 06):
- Bass style is a core table selected by a palette key (CONTEXT discretion, RESEARCH Pattern 4), so library files stay data-only and the chord and pickup rules live in one place. Style names: eighths, sixteenths, octave.
- RESEARCH Open Question 4: the style applies only where the core plays the bass from chord data. Under the classic progression the frozen classic bass generator keeps playing v1's rows whatever palette is picked (keeps the golden and the literal "classic must stay exactly v1"). Changing this later is a core-only change in render.scd.
- Style per palette (RESEARCH A8): acid and dark sixteenths; pluck octave (Plan 05); supersaw, warm and air eighths.
- Sixteenths: per beat one rest then three notes, dur 0.25, amp 0.1, legato 0.6 (a crisper roll); octave: offbeat eighths, root, root + 12, root, last, dur 0.5, amp 0.1, legato 0.8 (as the default bass).
</objective>
